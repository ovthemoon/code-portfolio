# 숨길 정보는 화면이 아니라 서버가 잘라서 보낸다

출처: 교실 실시간 그림 릴레이 게임(외주) (game.mjs, 2026-09)

## 문제
같은 방을 참가자 휴대폰, 진행자 화면, 공용 중계 화면이 함께 본다. 정답 단어나 앞 담당이 쓴 설명을 화면 코드에서 가리면 브라우저 개발자 도구에서 그대로 보인다.

## 해결
방 상태는 서버에 하나만 두고, 연결마다 보는 사람(`board`, `host`, `player`)과 단계에 맞춰 필드를 넣거나 빼서 보낸다. 숨길 값은 메시지에 아예 들어가지 않는다.
- 정답 단어: 출제 담당과 진행자에게만. 결과 단계에서 모두에게 공개한다.
- 설명 글과 그림: 다음 담당에게만. 공용 화면과 진행자는 작성 중인 내용을 실시간으로 본다.
- 정답 담당에게는 계속 숨기는 것이 아니라 단계적으로 공개한다. 오답이 나오면 단계가 넘어가며 그림, 설명 순서로 내려간다.
- 멈춘 방에서는 단서를 모두 뺀다. 종료된 방은 최소 필드만 보낸다.
- 토큰, 참가자 목록의 내부 값은 어떤 view에도 복사하지 않는다.

## 코드
- `project-view.mjs`: `projectView(room, viewer, now)`. 보는 사람과 단계별로 view를 만드는 순수 함수
- `project-view.test.mjs`: 단계 x 보는 사람 표로 각 view에 들어간 값을 직렬화한 문자열에서 찾아 검사

## 확인
```
cd js/server-side-view-projection && node --test
```

## 원본과 다른 점
- 점수, 팀 구성, 타이머, 연속 도전 모드 필드를 뺐다. 역할은 `room.roles`에 이미 정해져 있다고 가정한다 (원본은 팀과 차례에서 계산하고, 3인 팀에서는 진행자가 출제를 맡는다).
- 단계와 역할 이름을 일반화했다 (`author`, `illustrator`, `narrator`, `guesser`, `guess-0`부터 `guess-2`).
- 원본의 `projectRoom`은 시간 마감과 접속 상태를 반영하며 room을 바꾼다. 여기서는 바꾸지 않는다.
- 한국어 문구는 뺐다.
