# 질문을 기다리는 AI가 쉬는 것처럼 보이던 상태 표시

출처: OpenDesk (AgentEffectController.cs, ChatAskTools.cs, 2026-07 ~ 2026-08)

## 문제
AI가 사용자에게 질문하고 답을 기다리는데 캐릭터는 일을 마치고 쉬는 것처럼 보였다. 사용자는 질문이 온 줄 모르고 업무가 멈췄다. 원인은 여럿이었다. 상태를 정하는 코드가 처리 규칙 없는 신호를 모두 대기로 바꿨고, 물음표는 AI가 다시 움직이면 답한 것이라고 추측해 지웠으며, 서버의 실패 알림에는 어느 AI의 작업인지가 없었다. 질문 도구를 일반 작업 도구와 똑같이 작업으로 세는 문제도 있었다.

## 해결
- 이벤트마다 더하고 빼지 않고, 승인 대기 목록을 기준으로 모든 에이전트의 물음표를 매번 다시 계산한다. 한 번 놓쳐도 다음 계산에서 스스로 돌아온다.
- 대기 목록 갱신 알림이 대표 항목 하나만 싣거나 빈 목록일 수 있어서, 알림의 내용은 무시하고 전원을 다시 센다. 첫 수정은 알림의 에이전트 한 명만 다시 세다가 다음 날 전원 재계산으로 고쳤다.
- 질문 턴이 끝나거나 오류가 나면 그 에이전트의 물음표를 반드시 지운다. 사용자가 카드에 답하면 그 카드의 대기만 해제한다.
- 질문 도구 이름 목록을 따로 두고 작업 도구로 세지 않는다. 목록은 서버와 손으로 맞춘 사본이라 테스트가 서버 소스와 대조한다.

## 코드
- `excerpt/AgentEffectController.Approval.cs`: 대기 목록 전수 재계산, 턴 종료와 오류 때 해제, 답변 시 해제
- `excerpt/ChatAskTools.cs`: 질문 도구를 작업과 구분하는 목록 (파일 전체)
