# 홍보 영상을 실제 앱 화면으로 찍기 위한 Timeline 큐 트랙

출처: OpenDesk (ActorTrack.cs, ActorCueClip.cs, 2026-07 ~ 2026-08)

## 문제
홍보 영상을 CG 대신 실제 사무실과 실제 캐릭터 움직임으로 찍고 싶었다. 사무실 씬을 복사해 촬영용으로 쓰면 꾸미기가 바뀔 때마다 복사본이 낡는다. Timeline 애니메이션으로 캐릭터를 직접 움직이면 제품에서 실제로 걷고 앉는 코드를 찍는 것이 아니게 된다.

## 해결
- Timeline은 "이 시점에 걸어라, 앉아라" 같은 지시(큐)만 내리고, 걷기와 앉기는 앱의 실제 이동과 착석 코드가 한다. 클립 하나가 배우 한 명에게 내리는 큐 하나다.
- 큐는 재생 헤드가 클립에 들어갈 때 한 번만 실행한다. 표정과 제스처는 클립 길이만큼 유지한다.
- 편집 모드의 스크럽에서는 경로 탐색과 착석 같은 런타임 시스템을 돌릴 수 없어 재생 모드에서만 실행한다.
- 트랙에 바인딩된 배우가 촬영 캐스트에 없으면 큐가 조용히 사라지지 않게 한 번 경고한다. 걷기 큐에 목적지 마커가 없을 때도 경고한다.
- 큐 종류는 정수로 직렬화되므로 enum은 항상 끝에만 추가한다. 중간에 끼우면 기존 클립의 종류가 통째로 밀린다.
- 대가: 걷기 큐의 도착 시각은 이동 거리에 따라 달라진다. 연출에서 흡수한다.
- 사무실은 프리팹으로 빼서 앱과 촬영 씬이 함께 쓴다. 이 폴더에는 없다.

- `excerpt/ActorCueType.cs`: 큐 종류 enum과 추가 규칙
