# 돌진 뒤 캐릭터 몸통이 겹쳐 서로 밀려나던 문제

출처: 무림 히어로즈 (DashStopDistance.cs, 2026-09 ~ 2026-10)

## 문제
돌진이 목표 중심에서 고정 0.5m 앞, 최소 1m 이동으로 멈췄다. 두 캐릭터의 몸통(캡슐)이 항상 겹쳤고, 돌진이 끝나 캐릭터 컨트롤러가 다시 켜진 직후 첫 물리 틱에서 서로 밀려났다.

## 해결
- 멈춤 지점을 두 캡슐 반지름의 합에 여유 0.1m를 더한 거리로 계산한다.
- 이미 그 거리 안이면 돌진을 생략한다. 최소 이동거리를 강제하지 않는다.
- 같은 파일에서 돌진이 전투 창 가장자리를 넘어 도중에 끊기는 것도 처리한다. 창 안에서 갈 수 있는 거리로 줄이고, 창이 없으면 그대로 둔다.

## 코드
- `DashStopDistance.cs`: 이동 거리 계산과 창 안으로 줄이는 클램프
- `Tests/DashStopDistanceTests.cs`: 정지 간격, 이미 가까운 경우, 최대 거리 제한, 창 가장자리 케이스

## 확인
```
cd unity && dotnet test
```

## 숫자와 조건
원본 게임의 테스트 씬(Lab) 실측이다. 한 캐릭터 조합에서 돌진 거리 0.75m, 정지 여유 0.10m 고정, 돌진 뒤 밀림 0이었다.

## 원본과 다른 점
- Unity 벡터와 `Mathf`를 `System.Numerics`와 `System.Math`로 바꿨다.
- 전투 창 컴포넌트는 `ICombatWindow` 인터페이스로 대체했다. 테스트는 벽 하나짜리 창으로 검증한다.
- 컴포넌트에서 반지름과 높이를 읽는 메서드는 Unity 컴포넌트 의존이라 뺐다.
- 주석의 캐릭터 이름과 내부 작업 번호를 지웠다.
