# AI가 물어보고 할 일과 알아서 할 일을, 호출 하나의 무게로 가른다

출처: OpenDesk (call_weight.py, 2026-10)

## 문제
사용자가 메일 보내기를 "알아서"로 허락하면 받는 사람과 내용에 상관없이 그 종류의 호출이 전부 통과했다. 판단 단위가 도구 종류라서, 허락 한 번이 호출 하나하나의 위험을 가리지 못했다.

## 해결
호출 하나를 네 축으로 잰다. 모델에게 묻지 않고 인자와 기록에서 셀 수 있는 사실만 쓴다.

| 축 | 무겁다고 보는 경우 |
|---|---|
| 되돌릴 수 있나 | 발송, 공개, 결제, 삭제 같은 종류이거나 위험 분류기가 되돌릴 수 없다고 한 경우 |
| 누가 받나 | 주소록에 없는 사람이 있거나 대량인 경우 |
| 얼마인가 | 한도를 넘거나 금액을 읽지 못한 경우 |
| 해 본 일인가 | 승인받은 적이 없거나, 거절로 끊겼거나, 기한이 지난 경우 |

- 가장 무거운 축 하나가 등급을 정한다. 하나라도 무거우면 묻고, 중간이 있으면 하고 알리고, 모두 가벼우면 조용히 한다.
- 되돌릴 수 있는 종류에만 '알아서'를 준다. 보낸 메일은 알림을 받아도 할 수 있는 일이 없다.
- 자율로 여러 번 돈 항목도 정해진 횟수마다 한 번은 다시 묻는다(불시 점검). 난수 없이 횟수로 정한다.
- 시계, 저장소, 주소록은 모두 인자로 받는다. 순수 함수라 경우의 수를 표로 테스트할 수 있다.

## 코드
- `call_weight.py`: `weigh`(무게 재기), `decide`(등급 정하기)와 필요한 자료형, 추출 함수.
- `test_call_weight.py`: 축별 경우의 수, 등급 표, 세 가지 대표 호출의 끝에서 끝까지 판정.

## 확인
```
cd python && python3 -m pytest tool-call-weight
```

## 숫자와 조건
`MONEY_AUTO_LIMIT`, `SPOT_CHECK_EVERY`, `TRUST_TTL_DAYS`, `weigh`의 `bulk_threshold` 기본값 10은 **예시값**이다. 권한 칸(kind) 목록, 받는 사람 키 목록, 금액 키 목록도 예시 목록이다. 운영에서 쓰는 값과 다르다. 테스트는 상수에서 경계를 계산하므로 값을 바꿔도 통과한다.
코드와 테스트만 확인했다. 사용자 반응은 없다.

## 원본과 다른 점
- 위에서 말한 상수와 목록을 예시값으로 바꿨다. 권한 칸 이름도 일반 이름이다.
- 위험 분류기와 권한 설정 모듈은 가져오지 않았다. 분류기의 판정(`risk`, `gate_reason`)은 인자로 받는다.
- 원본은 이 두 모듈과 상수를 맞추는 테스트가 있다. 여기서는 뺐다.
- 문자열 금액은 통화 기호나 단위, 공백, 천 단위 쉼표를 뗀 나머지가 숫자 하나일 때만 읽는다. 그 밖에는 읽지 못한 것으로 보고 무겁게 다룬다(`1e9`, `1 000 000`, `5.000.000`, `99 + 999999`).
